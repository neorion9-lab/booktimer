# 📖 북(Book)적북적 자람나무 - 북타이머

학생 개인별 독서 시간을 한눈에 기록하고, 학급 전체의 독서 성장을 함께 확인하는 스마트 타이머입니다.

## 🌟 주요 기능
- **⏱️ 개인별 타이머**: 학생 번호를 클릭하면 개인 독서 타이머가 시작·정지됩니다.
- **🌳 학급 자람나무**: 학급 전체의 누적 독서 시간이 쌓일수록 나무가 새싹에서 사과나무로 성장합니다.
- **🏆 학생 랭킹**: 독서 시간이 있는 학생들의 랭킹이 실시간으로 우측 패널에 표시됩니다.
- **💾 자동 저장**: 브라우저 로컬 스토리지에 기록이 자동 저장되어, 브라우저를 닫거나 새로고침해도 누적 기록이 안전하게 유지됩니다.
- **⚙️ 맞춤 설정**: 학급 인원수(최대 50명), 학급 타이틀 등을 자유롭게 변경할 수 있습니다.
- **🤫 소음도 측정**: 교실 내 소음 수준을 실시간으로 파악하여 정숙한 독서 환경을 유도할 수 있습니다. (마이크 권한 필요)

## 🚀 시작하기 (사용 방법)
1. **파일 실행**: 브라우저(크롬, 엣지 등)에서 `index.html` 파일을 엽니다. 인터넷 없이도 작동 가능합니다.
2. **기본 설정**: 우측 상단의 ⚙️(설정) 버튼을 눌러 **학생 수 변경** 및 **제목 변경**을 통해 우리 반에 맞게 세팅합니다.
3. **독서 시작**: 책을 읽기 시작할 때 자신의 번호 버튼을 한 번 클릭합니다. (노란색으로 변하며 타이머가 돌아갑니다.)
4. **독서 종료**: 책 읽기를 마친 후 자신의 번호 버튼을 한 번 더 클릭하면 기록이 누적 저장됩니다.

## 🌳 자람나무 성장 단계
우측의 자람나무는 **학급 전체 누적 독서 시간 합계**를 기준으로 성장합니다. (1000분 단위로 사이클 반복)
| 단계 | 이모지 | 이름 | 달성 조건 |
|---|---|---|---|
| 1단계 | 🌱 | 새싹 단계 | 0분 ~ 249분 |
| 2단계 | 🌿 | 잎사귀 나무 | 250분 ~ 499분 |
| 3단계 | 🌸 | 꽃 피는 나무 | 500분 ~ 749분 |
| 4단계 | 🌳 | 사과 열매 나무 | 750분 ~ 999분 |

> 💡 **사과 열매 단계 특별 기능!** <br> 
> 학급 누적 독서 시간이 750분을 넘으면 나무 아래에 개인 누적 독서 시간이 500분 이상(해당 사이클에서 500분~999분)인 학생들의 번호와 누적 시간이 사과 이모지(🍎)와 함께 자랑스럽게 표시됩니다.

## 📘 상세 사용 설명서 (메뉴얼)
웹페이지 형태의 예쁘고 자세한 동료 교사 공유용 가이드라인이 필요하시다면, 함께 제공되는 **`manual.html`** 파일을 브라우저로 열어서 확인해 주세요. 해당 문서에 더 자세한 Q&A와 꿀팁이 담겨 있습니다.

## ⚠️ 관리 및 주의사항
- 설정 메뉴(⚙️)의 **'모든 학생 기록 초기화'** 기능은 누적 독서 시간을 영구적으로 0으로 만듭니다. 학기 초나 이벤트가 끝난 뒤에만 신중하게 눌러주세요.
- 타이머의 기록은 '현재 사용 중인 브라우저'에만 저장됩니다. 컴퓨터를 바꾸거나 다른 브라우저(크롬 쓰다가 엣지로 변경 등)를 사용하시면 기록이 연동되지 않으니 주의해 주세요!
